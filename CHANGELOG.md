# Changelog

## 0.2.0-alpha.1

- Reimplement the CLI in Rust while retaining `rfc show` compatibility.
- Add versioned JSON output and documented exit codes.
- Add RFC Editor metadata retrieval.
- Add persistent caching, offline mode, refresh control, and stale-cache fallback.
- Add an MCP stdio server with structured `get_rfc` and `get_rfc_metadata` tools.
- Add Cargo, PyPI, npm, Go bootstrap, direct archive, shell, and PowerShell distribution paths.
- Add cross-platform CI and release artifact attestations.
